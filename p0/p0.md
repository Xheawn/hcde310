## Resource 1: Open-Meteo

**What it provides:** Open-Meteo provides current weather estimates and hourly and daily forecasts for locations worldwide. Its data includes temperature, precipitation, wind speed, and precipitation probability.

**Docs link:** [Weather Forecast API documentation](https://open-meteo.com/en/docs)

**Access:** No API key is needed for the free, noncommercial API. The free limits are 600 calls per minute, 5,000 per hour, 10,000 per day, and 300,000 per month. Commercial use requires a paid subscription. Apps using the data must credit Open-Meteo. [Pricing and access details](https://open-meteo.com/en/pricing)

**Sample response** (trimmed):

URL: [Current weather near UW Seattle](https://api.open-meteo.com/v1/forecast?latitude=47.6553&longitude=-122.3035&current=temperature_2m,precipitation,wind_speed_10m&timezone=America%2FLos_Angeles)

```json
{
  "timezone": "America/Los_Angeles",
  "current_units": {
    "time": "iso8601",
    "interval": "seconds",
    "temperature_2m": "°C",
    "precipitation": "mm",
    "wind_speed_10m": "km/h"
  },
  "current": {
    "time": "2026-10-29T22:30",
    "interval": 900,
    "temperature_2m": 7.6,
    "precipitation": 0,
    "wind_speed_10m": 4.6
  }
}
```

**Who could this data help, and with what?**

1. UW students who walk or take the bus to campus could use weather forecasts to plan their commute in advance. On good-weather days, they may choose to walk and need to leave home earlier because walking takes longer than taking the bus.
2. People planning hiking trips could use weather forecasts to decide whether to go and what gear to bring, helping them prepare for the expected conditions.

**One risk:** Reliability: forecasts are estimates and may differ from actual local conditions. An inaccurate forecast could lead students to plan their commute poorly or hikers to bring gear that does not match the conditions they encounter.


## Resource 2: TheMealDB

**What it provides:** TheMealDB provides recipes with ingredients, measurements, cooking instructions, images, and categories. Recipes can be searched by name or filtered by ingredient, category, or cuisine area.

**Docs link:** [TheMealDB API documentation](https://www.themealdb.com/api.php)

**Access:** Basic development and educational use is free with the shared test API key `1`, included in the request URL. A paid supporter subscription is required for app-store publication and premium features such as filtering by multiple ingredients. The official API documentation does not specify a numeric request-rate limit. [API access details](https://www.themealdb.com/api.php), [terms of use](https://www.themealdb.com/terms_of_use.php)

**Sample response** (trimmed):

URL: [Search for Arrabiata](https://www.themealdb.com/api/json/v1/1/search.php?s=Arrabiata)

```json
{
  "meals": [
    {
      "idMeal": "52771",
      "strMeal": "Spicy Arrabiata Penne",
      "strCategory": "Vegetarian",
      "strArea": "Italian",
      "strIngredient1": "penne rigate",
      "strMeasure1": "1 pound",
      "strIngredient8": "Parmigiano-Reggiano",
      "strMeasure8": "sprinkling"
    }
  ]
}
```

**Who could this data help, and with what?**

1. UW students living off campus could find recipes featuring an ingredient they already have and create a shopping list of the remaining ingredients. This could help them use food before it goes to waste.
2. People learning to cook for themselves could use an app that turns recipe instructions and ingredient lists into cooking checklists, helping them follow unfamiliar recipes and keep track of their progress.

**One risk:** Some measurements are imprecise. For example, this response lists “sprinkling” as an amount. This makes automatically calculating shopping quantities or adjusting serving sizes less reliable.
